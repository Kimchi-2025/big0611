ADP 필기 기준 추천 학습 순서

지금까지 우리가 통계(가설검정, 확률분포 등)를 공부한 흐름과 자연스럽게 이어지도록 한다면 다음 순서를 추천합니다.

1. 머신러닝 개요 (AI → 머신러닝 → 딥러닝, 지도학습 vs 비지도학습)
2. 평가 지표 (혼동행렬, Accuracy, Precision, Recall, F1, ROC-AUC, 과적합/과소적합, 교차검증)
3. 분류분석 (로지스틱 회귀, 의사결정나무, KNN, Naive Bayes, SVM)
4. 앙상블 분석 (Bagging → Random Forest → Boosting → AdaBoost → Gradient Boosting → XGBoost)
5. 인공신경망 분석 (퍼셉트론 → 활성함수 → 역전파 → MLP → CNN/RNN 개요)
6. 군집분석 (K-Means → 계층적 군집 → DBSCAN → 군집평가)
7. 연관분석 (Apriori, FP-Growth, Support, Confidence, Lift)
8. 비정형 데이터 마이닝 (텍스트 마이닝, TF-IDF, Word2Vec, BERT, LLM 개요)

이 순서대로 진행하면 각 주제가 앞에서 배운 개념 위에 쌓이기 때문에 암기보다 이해 중심으로 공부할 수 있습니다. 
특히 2번(평가 지표)를 먼저 넣은 이유는 이후 분류, 앙상블, 신경망을 공부할 때 모든 모델의 성능을 같은 기준으로 
비교할 수 있기 때문입니다.
