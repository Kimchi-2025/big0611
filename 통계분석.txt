    ├── 정규분포 (Normal)
    │    └── 표준정규분포(Z분포)

    ├── F분포

------------------------------------------------------------------------------------------------------
| 이름  | 의미            |
| PDF  | 확률밀도함수  |
| CDF  | 누적분포함수  |
| PPF   | CDF의 역함수 

| 분포           | CDF 함수    |
| 정규분포      | `norm.cdf()` |
| t분포          | `t.cdf()`       |
| F분포          | `f.cdf()`       |
| 카이제곱분포 | `chi2.cdf()`  |

| 함수            | 언제 사용?            |
| -------------  | -----------            |
| `norm.pdf(x)`  | 분포의 높이, 그래프 |
| `norm.cdf(x)`  | 누적확률              |
| `norm.sf(x)`    | 오른쪽 꼬리 확률    |
| `norm.ppf(p)` | 분위수(임계값)       |

PDF는 확률분포의 모양(확률밀도)을 나타내는 함수이고, CDF는 PDF를 적분해서 누적확률을 계산하는 함수이다. 
실제 확률은 CDF(또는 CDF의 차이)를 이용해 계산한다. p-value도 결국 CDF를 이용해 계산한 확률이지만, 
가설검정에서 '관측된 통계량보다 같거나 더 극단적인 결과가 나올 확률'이라는 특별한 의미를 가지므로 별도의 이름으로 부른다.

변수 간 관계	Pearson/Spearman

즉 H0/H1은 검정 방법을 선택하는 순간 거의 결정되고, 범주형 데이터 분석은 "숫자의 크기를 비교하는 것이 아니라 
범주별 빈도·비율·관계를 분석하는 것"이라고 이해하면 됩니다.

p-value의 의미
"귀무가설이 참이라고 가정했을 때, 내가 관측한 통계량(Z/T/F)이 얼마나 극단적인가?"
"내 z값이 z분포에서 얼마나 극단적인가?"
"내 t값이 t분포에서 얼마나 극단적인가?"
"내 F값이 F분포에서 얼마나 극단적인가?"
z=2.5 -> 평균이 정말 기준값과 같다면(z=0 근처라면), z=2.5 같은 값이 얼마나 자주 나오는가?
t=3.1 -> 귀무가설이 참이라면 t=3.1처럼 큰 값이 얼마나 나오는가?
F=6.8 -> 모든 그룹 평균이 같다면 F=6.8처럼 큰 분산비가 얼마나 나오는가?

Z값의 의미: "평균에서 몇 개의 표준편차만큼 떨어져 있는가" -> 관측값이 평균에서 얼마나 떨어졌나 -> 표준편차(σ)
Z = (관측값과 평균의 차이) / (데이터의 표준편차(σ))
T값의 의미: "평균 차이가 표준오차 기준으로 몇 배 떨어져 있는가" -> 표본 평균이 가정한 평균에서 얼마나 떨어졌나 -> 표준오차(SE)
T = (관측된 평균 차이) / (평균 차이의 일반적인 변동(SE))
F값의 의미: "설명되는 변동이 설명되지 않는 변동보다 몇 배 큰가" -> 그룹 간 차이가 내부 변동보다 얼마나 큰가 -> 분산
F = (집단 간 변동) / (집단 내 변동)
F=10 -> 그룹 간 차이가 내부 변동보다 10배 크다 -> 그룹 평균이 다를 가능성이 높음

- z와 t 비교-
		z		t
비교 대상		관측값 vs 평균	표본평균 vs 가정한 평균
기준		표준편차 σ	표준오차 SE
의미		몇 σ 떨어졌나	몇 SE 떨어졌나

그래프 관점에서 보면...
- Z/T분포 -
오른 쪽으로 멀어질 수록 "귀무가설 아래서 보기 어려운 값"

- F분포 -
F분포는 음수가 없고, F값이 클수록 "관측된 그룹 차이가 우연한 변동보다 크다"

결국 통계량들은 모두 같은 철학이다
통계량 = (관찰된 효과) / (우연히 생길 수 있는 변동)

z: 효과 / 표준편차
t: 효과 / 표준오차
F: 집단 차이 / 내부 변동
